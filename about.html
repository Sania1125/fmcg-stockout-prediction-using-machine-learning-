PROJECT NOTES

About the study

Dataset

Retail Store Inventory Forecasting Dataset, downloaded from Kaggle. The publisher describes it as synthetic yet realistic; it is CC0 Public Domain. The raw file is kept unchanged in data/raw/ and contains 73,100 rows and 15 columns.

Target and leakage control

stockout_within_7_days is derived as 1 when, on any of the next seven days for the same Store ID + Product ID, observed inventory is no greater than observed units sold. Future rows are used only to create the label; rolling velocity and variability use shifted historical sales only. The final seven observations of each series are excluded because they lack a complete horizon.

Feature mapping

Inventory Level → current stock; Units Sold → sales velocity and demand variability; Holiday/Promotion → promotion status; Price, Discount, Category, Region, Weather Condition and Seasonality are used directly. The source has no supplier lead-time field, so the project uses an explicit 3-day planning assumption and discloses it as a limitation rather than presenting it as source data.

Limitations

The dataset is synthetic, the target is a proxy rather than an observed stockout label, and the fixed lead-time assumption is not learned from suppliers. Results are suitable for coursework demonstration, not production purchasing.
